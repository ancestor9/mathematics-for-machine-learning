### 1. 학습 내용 및 목표
- 이제는 교수 강의나 기초 이론부터 배우는 게 아니라, 해결할 문제를 먼저 정한 뒤 LLM을 도구로 삼아 질문을 쪼개어가며, 최종적으로는 인간이 해결방식과 코드를 완벽히 이해하고 주도권을 쥐는 방식으로 공부(일)해야 한다는 뜻

### 2. 학습 내용
- Linear Algebra dir에는 통계와 확률을 학습하고 선형대수(행렬과 벡터 연산)와 pytorch, 모델링과 시뮬레이션 까지

### 3. 학습 방법 
- 대학은 인생의 문제해결을 위한 훈련연습소이지만 AI가 보편화 되면서, 인공지능(LLM) 시대의 새로운 학습 및 문제 해결을 위한 [Paradigm_shift](https://en.wikipedia.org/wiki/Paradigm_shift) 가 필요!

#### 3.1. ‘탑다운(Top-Down)’ 방식으로의 전환
- 기존 방식 (Bottom-Up): 기초 문법이나 이론부터 차근차근 배워서 나중에 큰 문제를 푸는 방식(전통적인 학교교육 시스템)
- 새로운 방식 (Top-Down): 이제는 ‘해결해야 할 문제(전체 그림)’를 먼저 정의하고, 이를 해결하기 위해 거꾸로 세부적인 내용을 파고드는 방식으로 대 전환이 필요

#### 3.2. LLM(인공지능)의 역할 변화: ‘해답지’가 아닌 ‘드릴(Drill)’
- 과거처럼 교수나 강사에게 의존할 필요가 없어졌음
- LLM에게 단순히 답을 달라고 요청하는 것에 그치지 않고, 질문을 끊임없이 세분화(Drill down)하며 질문하는 과정 자체를 통해 전체 프로세스를 스스로 이해해 나가는 것이 핵심

#### 3.3. 주도권은 인간에게: 코드를 ‘이해’하는 주체가 될 것
- 잘못된 방식: LLM에게 내 문제와 코드를 다 떠먹여 주며 "네가 알아서 이해하고 고쳐줘"라고 의존하는 방식
- 올바른 방식: AI가 코드를 짜줄 수는 있지만, 그 코드가 왜 그렇게 작동하는지 ‘이해’하고 통제하는 주체는 반드시 인간(나 자신)이어야 함
